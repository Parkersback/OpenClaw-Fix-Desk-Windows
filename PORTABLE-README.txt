OpenClaw Fix Desk Windows Portable

用法：
1. 确保这台 Windows 已安装 Node.js，且 openclaw 命令可直接使用。
2. 双击 start.cmd 启动。
3. 或双击 launch-hidden.vbs 静默启动。
4. 打开 http://127.0.0.1:41891
5. 停止时双击 stop.cmd

主要功能：
- OpenClaw Gateway 状态诊断
- 一键重启 Gateway
- doctor repair + gateway restart
- OpenAI / Codex 重新登录入口
- 常见日志错误查看
